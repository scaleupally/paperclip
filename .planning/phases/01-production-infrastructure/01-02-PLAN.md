  fly certs add agents.midstage.ac --app paperclip-icy-fog-8513

  fly certs show agents.midstage.ac --app paperclip-icy-fog-8513

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI stdout -> user browser | Bootstrap invite URL contains a one-time token; exposed only via local terminal |
| DNS propagation | CNAME record is public; no secret data, but incorrect target would route traffic elsewhere |
| Internet -> agents.midstage.ac | Custom domain with TLS; same trust boundary as the .fly.dev domain |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing | Bootstrap invite URL | mitigate | Token is SHA-256 hashed before DB storage (auth-bootstrap-ceo.ts); invite is single-use with expiry; URL transmitted only via local CLI stdout |
| T-02-02 | Elevation of Privilege | Workspace creation | mitigate | POST /api/companies guarded by `assertInstanceAdmin(req)`; only the bootstrapped admin can create workspaces |
| T-02-03 | Spoofing | Custom domain DNS | mitigate | Fly.io issues TLS cert via Let's Encrypt only after DNS validation; force_https=true prevents HTTP downgrade |
| T-02-04 | Information Disclosure | PAPERCLIP_ALLOWED_HOSTNAMES | accept | Secret stored encrypted in Fly.io; value contains only public hostnames (not sensitive) |
| T-02-05 | Tampering | DNS CNAME record | accept | Standard DNS risk; mitigated by TLS -- even if DNS is poisoned, cert won't validate for wrong origin |
</threat_model>
