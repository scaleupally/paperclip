## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions -> Fly.io | FLY_API_TOKEN authenticates deploy; if leaked, attacker can deploy arbitrary code |
| Internet -> /api/health | Public endpoint, returns non-sensitive status info |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | GitHub Actions deploy | accept | FLY_API_TOKEN is a GitHub encrypted secret; standard GH Actions security model applies |
| T-01-02 | Information Disclosure | /api/health response | accept | Returns only status and bootstrapStatus — no PII, no internal details, low-value target |
| T-01-03 | Denial of Service | Health check endpoint | mitigate | Fly.io rate-limits health probes internally; the endpoint does only `SELECT 1` (minimal DB load) |
| T-01-04 | Tampering | fly.toml / CI config | accept | Protected by branch protection and git history; changes are code-reviewed via PR or visible in commit log |
</threat_model>
